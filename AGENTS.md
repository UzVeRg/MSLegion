# Инструкции Codex для MSLegion

1. Начинай с [указателя Codex](docs/models/codex/README.md). Затем открывай только нужные для задачи разделы и указанные в них исходники.
2. Проверяй факты о текущем поведении по соответствующему коду, конфигурации или тестам. Проверяй цели и планы по документам в `docs/team/`.
3. После каждого нового существенного решения или изменения в рамках той же задачи сверяй указатель, карту исходников и сведения о проекте в `docs/models/`. До завершения задачи внеси новые и изменившиеся сведения во все затронутые файлы, включая решения, которые ещё предстоит реализовать. Добавляй записи только в конец соответствующего Markdown-файла. Сохраняй весь прежний текст, включая уже добавленные записи, байт в байт. Формат описан в [указателе Codex](docs/models/codex/README.md).
4. Обновляй инструкции для команды в `docs/team/` на русском языке. Храни значения секретов за пределами документации и базы Codex.
5. Каждое значимое изменение после проверки закоммить и отправь с локальной машины на GitHub в рабочую ветку проекта до завершения задачи. Пропускай отправку, если в текущем запросе явно указано обратное. Включай в коммит только изменения задачи. Если отправка не удалась, сообщи причину и укажи локальный коммит.

6. Пиши на русском языке комментарии в исходниках, сообщения журналов и консоли, другие тексты для людей и инструкции для команды. Сохраняй машинные ключи, коды, идентификаторы и значения протоколов в установленном виде.

7. После отправки каждого изменения на GitHub выпусти проверенный коммит из `main` на VPS, примени его с перезапуском затронутых сервисов и проверь публичные `/health`, `/ready` и изменённый сценарий. Для изменений интерфейса проверь, что публичный стенд отдаёт новую сборку, и открой Mini App в Telegram, когда доступна проверка из клиента. Порядок выпуска описан в [руководстве по VPS](docs/team/development/vps.md). Если текущая задача исключает выкладку или выполнение заблокировано, сообщи статус и причину.

8. Для каждой новой вкладки Mini App подготовь и проверь оформление во всех четырёх темах. Используй общие компоненты и переменные тем. См. [темы Mini App](docs/team/design/mini-app-themes.md).
