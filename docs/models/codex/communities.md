# Сообщества MSLegion

## COMM-01 — Сообщества и членство

- HTTP API находится в `backend/app/modules/communities/router.py`, права и операции — в service.py, выборки — в repository.py, модели — в models.py.
- Создатель становится владельцем. Владелец добавляет и исключает существующих пользователей по UUID. Участники видят только свои сообщества. Остальные получают 404, а участники при операции владельца получают 403.
- Миграция `20261120_0005` добавляет `communities` и `community_memberships`. Пара UUID сообщества и пользователя уникальна.
- Сценарий PostgreSQL проверяет изоляцию, конкурентное добавление и прекращение доступа после исключения.
- Источники — указанные исходники, `backend/tests/test_integration_postgres.py` и `docs/team/reference/api.md`.
